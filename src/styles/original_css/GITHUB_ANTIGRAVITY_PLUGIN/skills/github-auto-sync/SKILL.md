# GitHub Auto-Sync & Repository Manager Skill

Use this skill whenever you need to:
1. Audit and clean workspace (remove scratch files, logs, temp dumps).
2. Scan for secrets and enforce .gitignore.
3. Auto-generate high-quality README.md with screenshots & PRESENTATION.md slides.
4. Auto-create GitHub repository on user profile if it doesn't exist.
5. Auto-update repository description & topics on GitHub.
6. Push changes cleanly with conflict auto-resolution.
7. Audit and update missing descriptions for older repositories on GitHub.
